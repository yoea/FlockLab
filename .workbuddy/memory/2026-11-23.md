# 2026-11-23 FlockLab v40

## 本次改动（已提交并推送 695ade9）

1. **「不变紫」根因**：`render()` 里色阶算的是 `neighbors[i] / 24`，而 `neighbors` 自 v31 起是「注意力邻居数」（`NEIGHBOR_CAP = 7`），上限只能到 7/24 = 0.29 → 色相上限 `0.52 + 0.29×0.4 ≈ 0.64`（蓝绿）。`localDen` 算了却没人用。改用 `localDen[i]`，`LOCAL_DEN_K` 70 → 160，且 denK 改按 `sqrt(n/800)` 缩放（原按 n 线性，是给「铺满全屏」调的）。
2. **「散成一坨坨」根因（两条）**：
   - v38 的穿墙是「关于场地中心对称」（x=-hx 且 y 取反），每次跨边界把鸟群复制成 ±y 两份镜像 → 永久撕开。25 秒内 800 只累计穿墙 1500 次，群体 1 → 6~8 坨。改成**纯平移**（对侧同 y）。
   - 只有 7 只拓扑邻居时，两坨鸟距离一超过视野 7 就互不可见，分离力把群体压成结晶小团，**调 cohesion/separation 只会更碎**（cohesion 3.2 → 17 坨）。加弱长程归拢：`FLOCK_KEEP_R=18 / FLOCK_KEEP_F=14`，只对离质心超过 R 的个体施力，半径按 `sqrt(n/800)` 放大（否则 3000 只会压成实心球）。质心与 `groupRms` 改**最小映像**（否则穿墙那帧质心跳到对面，归拢方向整反）。
   - 实测 800 只：5~9 坨 / RMS 42 → 1~2 大团（偶发 3~4）/ RMS 22~26，`sepStats.below05 ≈ 0.1`。
3. **音量**：`musicLevel` / `fxLevel` 固定 1.5，从 `PERSIST_KEYS` 移除（老存档 0.4 不再生效），面板「声音」分组删除，只留声音开关。
4. **音效**：`predDash()`（气流 720→170Hz + 锯齿下行嘶鸣，包络边沿 0.30 触发 + 400ms/只限流）；`land()` 加五声音阶下滑尾音，`takeoff()` 改两声上行小音。
5. **背景**：`bgMat` 换 fbm 双层星云 + 0.6% 闪烁星点；`dustMat` 380 颗在顶点着色器上浮/游走 —— **`dustMat.uniforms.uTime` 以前从未被更新，浮尘一直是死的**。
6. **面板**：新增 `wrapEdges`「屏幕边缘穿越」开关，关掉走 `bounceOffWall()`（夹回 + 反转分量 ×0.92），鸟 / AI 捕食者 / 鼠标捕食者三处一致，鼠标的**光标目标**也要夹进场内。

## 验证方法（下次直接用）

- 本地：`python -m http.server 8777` + 无头 Chrome `--remote-debugging-port=9222`，Node 22 自带 WebSocket 走 CDP。
- **探针脚本在 `%TEMP%/flprobe/`**：`probe.mjs`（采样 + 单链接聚类数坨）、`ab.mjs`（A/B 归拢开关）、`aud.mjs`（手势解锁音频后读 `FlockLab.soundEvents` 验证各音效真的在响）。
- 关键坑：**必须先 `localStorage.clear()`**，否则上一次测试写进去的 count/cohesion 会污染测量（一度把 sep below05 读到 0.54，误判成归拢把鸟压重叠）。
- 「散成几坨」只能靠 `FlockLab.positions` 做连通块聚类判断，`groupRms` 分不清 1 坨大群和 5 坨小群。
